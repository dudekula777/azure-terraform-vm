# Azure VM Provisioning with Terraform

This project automates the provisioning of Azure VM instances using Terraform, with automated installation of Docker and Nginx through GitHub Actions.

## Features

- 🚀 **Infrastructure as Code**: Complete Azure environment defined in Terraform
- 🔒 **Security**: Automated SSH key generation and network security groups
- 🐳 **Docker**: Automated Docker installation and configuration
- 🌐 **Nginx**: Web server setup with custom landing page
- ⚡ **CI/CD**: GitHub Actions workflow for automated deployments
- 🏗️ **Modular Design**: Reusable Terraform modules
- 🌍 **Multi-Environment**: Separate configurations for dev and prod
